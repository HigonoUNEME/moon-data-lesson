もう一つの道具：自由探索ツール

notebooks/explore.ipynb … コードを書かずに、プルダウンで データセット・X軸・Y軸・色分けを選んで散布図を見比べる。「どの組み合わせが面白いか」を まず手で探したいときに使う。見つけた関係を、上のヘルパーでくわしく調べる。

よくある詰まり
・列名の大文字小文字：'クレーター年代' だけ Lat / Lon / Diam_km と大文字。他は小文字。
・対数グラフのエラー：その列に 0 以下の値がある。df[df['列'] > 0] でしぼってから。
・site_score の結果に _norm_... 列が出る：各条件を0〜1に直した値。気にしなくてよい。
・温度の t_swing_K などが出ない：先に daily_swing(df) を通す必要がある。

各データの列（何が入っているか）

データ列
クレーターlat, lon, diam_km, diam_major_km, diam_minor_km, eccentricity, ellipticity, rim_arc_fraction
クレーター深さlat, lon, diameter_km, depth_km, depth_diameter_ratio
クレーター年代Lat, Lon, Diam_km, Age (1〜5), Age_name
温度lat, lon, temp_noon_K, temp_midnight_K, temp_diff_K, t_lt00 … t_lt23
極域日照lat, lon, average_illumination_percent, permanent_shadow_fraction, slope_deg
地質lat, lon, relative_age, age_index (1古〜5新), 区分 (海/陸)
着陸地点name, kind, lat, lon, terrain, year, note
環境lat, lon, 区分, age_index, temp_max_K, temp_min_K, temp_amp_K, night_min_K, noon_sun_elev_deg, earth_elev_deg (正=表側/負=裏側)
地域name, lat_min, lat_max, lon_min, lon_max, rationale, caveat
縦孔name, lat, lon, host_terrain, opening_m, depth_m

注意：日照率・傾斜の絶対値は他資料と単純比較しない（順序のみ）。傾斜は極点から0.7度より外。 クレーターの深さは“今の深さ”。海の区分は円近似（約19%）と USGS 地質図（約16%）で違う。
