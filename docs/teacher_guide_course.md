## ステップ1：月の温度は1日でどれくらい変わる？

- **学習目標**：(1) 分散（ばらつき）が「1日の温度のふれ幅」という物理量に対応することを体感する。
  大気がない＝温室効果も熱の運搬もない＝放射だけ、を理解する。**(2) データが信頼できる範囲を
  自分で確かめる**（極では温度カーブが崩れる）。生の温度カーブはこの後は使わず、
  ステップ3では `環境` データにまとめた「1日の温度差（`temp_amp_K`）」を場所の指標の一つとして使う。
- **操作**：`my_band` に緯度の範囲を入れて実行。`diurnal_curve` でカーブ、`daily_swing`＋`summary` で数値。
  最後に `my_band=(-90,-80)` も試させる。
- **想定される結果**：赤道（`(-10,10)`）で1日の温度差 `t_swing_K` ≈ **290 K**（＝約290℃）。
  いちばん暑いのは正午すぎ、いちばん寒いのは明け方（4〜5時）。緯度を上げると差は小さくなる。
  南極付近（`(-90,-80)`）ではカーブが平坦・ガタガタで温度差も小さい。
- **生徒のつまずき**：
  - 「分散」と「温度差」が結びつかない → 「カーブが大きく上下する＝ばらつきが大きい＝1日の差が大きい」と言い換える。
  - カーブが左右対称だと思っている → 実際は「朝は急に上がり、夕方以降はゆっくり下がる」。
- **問い返しの例**：
  - 「地球の砂漠は昼夜差20〜30℃。月は290℃。この差はどこから？」
  - 「日没後すぐに氷点下にならず、しばらく暖かいのはなぜ？」（地面が熱を蓄えている＝熱慣性）
  - 「南極付近でカーブが崩れたのはなぜ？　このデータはそこで信じていい？」
- **極の扱い（重要）**：極ではカーブが崩れる。これは①データの限界（現地時間の刻みが粗い）
  ②物理（極では太陽が地平線を回るだけで『昼夜』がはっきりしない）の両方。
  **ここでは中立に「極では日較差が小さいが、温度データも不確か」と押さえるだけにする**
  （旧版はここで「極が基地に向いている」と結論を先出ししていた＝南極バイアスの起点だった）。
  極を細かく評価するときは温度ではなく LOLA の日照データを使う（ステップ4b）。
- **温度の意思決定上の役割**：日較差 290 K は「赤道・低緯度は熱ストレスが大きい」という
  ステップ4 のスコアの一材料（`temp_amp_K`）。ただし「だから赤道はダメ」ではなく、
  「赤道を選ぶなら熱対策と蓄電が要る」という**条件**として扱う。

## ステップ2：月の「海」と「陸」で何が違う？

- **学習目標**：群比較（グループに分けて統計量を比べる）。空間的なかたよりが時間的な歴史（新旧）を
  語ること。**分類は「発見の後」に来る**（箱を先に与えない）。
- **操作**：(1) `grid_count` で全球のクレーター密度マップ → 低密度の帯を生徒に探させる。
  (2) `scatter(load('クレーター'),'lon','lat')` で月面画像に重ねる → 低密度帯＝黒い海だと気づかせる。
  (3) `near_maria(load('クレーター'), scale=my_scale)` で**公式の海の座標**（USGS 地名辞典23海）を
  使って数値化 → `value_counts` と `summary_by`、`クレーター年代` の `Age` 平均も比べる。
- **想定される結果**（`my_scale=0.8`）：クレーター密度は陸／海 ≈ **3.5 倍**（海 2,232 個・陸 34,145 個）。
  直径の平均は海 24 km・陸 17 km（海に古い巨大盆地が残るため。件数の差が本筋）。年代インデックス
  平均は海 3.15・陸 2.96（海の方がやや新しい。`my_scale` を下げると差がわずかに開く）。
- **生徒のつまずき**：「海に隕石が落ちなかった」と考える → 落ちた数は同じ。落ちた**後**に
  溶岩でおおわれて古いクレーターが消えた（＝海のほうが若い）。
- **問い返しの例**：
  - 「クレーターが少ない＝新しい、と言えるのはなぜ？」
  - 「`my_scale` を 0.5 にすると差はどうなる？　なぜ？」（中心部ほど溶岩が厚い＝若い）
- **答え合わせ（cell の後半・重要）**：`load('地質')`＝USGS 統合地質図。`summary_by(geo,'区分','age_index')`
  で **海 3.15・陸 2.32**（数字が大きいほど新しい）→ クレーターからの推定と一致。
  海の面積割合は**円近似 18.7% ／ USGS 地質図 15.7%**（文献値 約16%）。
  - 「あなたのクレーターからの推定は、プロの地質図と合っていた？」
  - 「円で海を囲むと大きめに出るのはなぜ？」（海岸線の外の陸も丸に入る＝近似の限界。情報Ⅰ「データの妥当性の検討」）
- **craters_3d の『深さ』を扱う場合の注意**：`クレーター深さ` の d/D は 0.08 前後で、教科書の「単純
  クレーター 0.2」より小さい。これは**数十億年の埋積・崩壊を経た“今の深さ”**だから。
  「単純クレーターは深い」の確認には使わず、「大きさ・古さとともに浅くなる」傾向を見る。
- **最終ゴールとの接続（板書）**：海は平らで**着陸しやすい**が若い。高地は古くてでこぼこ。
  氷は極にしかない。**どれを重く見るかは基地の目的しだい** → ステップ3で月全体の環境を見て、
  ステップ4で目的別に評価する。

## ステップ3：月全体で環境を見る

- **学習目標**：基地選びの指標（熱ストレス・地球の見えかた・太陽高度）を全球で俯瞰し、
  **「どこも全部で一番にはならない」**ことを掴む。ここが「南極ありき」を崩す肝。
- **操作**：`env = load('環境')`。`scatter(env,'lon','lat',color='temp_amp_K')` /
  `color='earth_elev_deg'` / `color='slope_deg'` で全球マップ。次に4つの地域タイプ（赤道の海・
  中緯度の火砕丘・裏側・南極）の平均値を表で比べる。
- **想定される結果**（`env` は既存データの結合＋幾何計算。`slope_deg` のみ LOLA LDEM_16 由来。
  `tools/build_site_environment.py` ＋ `tools/build_global_slope.py`）：

  | 地域 | 日較差 temp_amp_K | 夜の底 night_min_K | 太陽高度 | 地球の仰角 earth_elev_deg | 傾斜 slope_deg |
  |---|---|---|---|---|---|
  | 赤道の海（静かの海） | ≈ 296 K | ≈ 95 K | ≈ 82° | **+59°**（地球ほぼ真上） | **≈ 1.0°**（平ら） |
  | 中緯度の火砕丘（Aristarchus） | ≈ 286 K | ≈ 94 K | ≈ 66° | +37° | ≈ 1.3° |
  | 裏側・赤道（電波天文の候補域） | ≈ 291 K | ≈ 94 K | ≈ 82° | **−76°**（地球は地平線の下） | **≈ 6.7°**（でこぼこ） |
  | 南極（Shackleton-de Gerlache） | **≈ 127 K** | ≈ 48 K | ≈ 2° | ≈ 0°（地球は地平線すれすれ） | ―（\|lat\|≥85° は NaN。極域はステップ4b の LOLA 傾斜で） |

- **問い返しの例**：「温度が安定・地球が見える・日がよく当たる、が全部そろう場所はあった？」
  「あなたのミッションで、この4列のうちいちばん大事なのはどれ？」
- **注意（生徒に伝える）**：`temp_amp_K` の曲線の形は極で不確かだが「昼どれだけ熱く・夜どれだけ
  冷えるか」の目安には使える。`earth_elev_deg` は秤動（±約7°）を無視した平均で、境界（±10°以内）は
  「地球が地平線近く」。`noon_sun_elev_deg` は地形無視の幾何近似。`slope_deg` は LOLA 標高から
  計算した基線 ≈1.9km の起伏の指標で、絶対値は工学判断に使わず「平ら／でこぼこ」の順序だけ使う
  （極域〈\|lat\|≥85°〉は等緯度経度グリッドが破綻するため NaN。極の傾斜は `極域日照` の 240m 版）。

## ステップ4：地域タイプを選んで、ミッションに合わせて評価する

- **学習目標**：複数の指標を 0〜1 に正規化し重みをつけて**スコア式を設計**する。
  **選んだ地域とミッションで、答えが半球ごと変わる**ことを体験する。
- **操作**：`my_region` に `load('地域')['name']` から1つ選び、`region = region_type(load('環境'), my_region)`。
  `want` に指標と重みを書いて `site_score(region, want, top=10)`。
- **ミッション → 選ぶ地域と `want`（教員用の答え）**：

  | ミッション | 選ぶ地域 | `want` の例 | 落ち着く先 |
  |---|---|---|---|
  | ☀️ 太陽光発電 | 「赤道の海」と「南極」を**両方**試す | `noon_sun_elev_deg` 高2・`temp_amp_K` 低2 | 赤道＝太陽高いが日較差 300K／南極＝日較差小だが太陽低い。**議論が割れる**（→有人と同じく 4b で南極を細見） |
  | 🔭 電波天文台 | 「裏側・赤道（電波天文の候補域）」 | `earth_elev_deg` **低3**・`temp_amp_K` 低2 | 経度 180° 付近、`earth_elev_deg ≈ −87°`（地球が最も深く隠れる） |
  | 🧊 氷採掘 | 「南極（Shackleton-de Gerlache）」 | （環境データに永久影が無い）→ **ステップ4b へ** | 南極 PSR。目的が明確なので答えも1つに近い |
  | 🏠 有人総合 | いくつか試す＋4b | `noon_sun_elev_deg` 高1・`temp_amp_K` 低2・`earth_elev_deg` 高1・`night_min_K` 高1 | 表側の中〜低緯度か、南極の日照尾根。バランスの取り方で動く |

  → **氷採掘＝南極／電波天文＝裏側／通信・有人＝表側寄り**。「1つの正解」ではなく
  「目的が最適地を決める」ことを、班ごとの結果の違いで見せる。
- **`earth_elev_deg` の向き**：`('低い', ...)` にすると「地球が見えない裏側」を高評価（電波天文）。
  `('高い', ...)` なら「地球がよく見える表側」を高評価（通信）。ここを取り違えると逆の場所が出る。
- **生徒のつまずき**：地域を選ばずに全球で `site_score` すると、`temp_amp_K` が飛び抜けて小さい
  南極ばかりが上位に来る → **「まず地域タイプを選ぶ」**を徹底する（それが目的の言語化になる）。
- **書かせるもの**：選んだ地域・スコア式（重み）・上位の緯度経度・「ここに建てる」1地点＋理由3文。

## ステップ4b：（氷採掘・南極を選んだ班）南極を細かく見る　― 別ノートブック `course_moonbase_polar.ipynb`

- **対象**：氷採掘の班、または太陽光・有人で「南極」を候補にした班のみ。他の班はステップ5へ。
  本体 `course_moonbase.ipynb` のステップ4b は「該当する班はこちらを開く」という案内だけ。
- **学習目標**：ヒストグラムから自分でしきい値を決める。**日当たりと平らさが同じ場所にあるとは
  限らない**ことを数で確かめる。
- **操作**：`course_moonbase_polar.ipynb` を開く。旧ステップ3＋4の中身：`south_pole(load('極域日照'))`
  で日照率・傾斜のヒストグラム＋しきい値、`dist_to_permanent_shadow(...)` ＋ `site_score(極, want_pole)`。
  終わったら本体のステップ5に戻る。
- **想定される結果**：
  - 傾斜 ≤ 5°：南極域の約 12%／≤ 8°：約 40%／≤ 10°：約 58%（平らな場所は貴重）
  - 「日照 ≥ 30% かつ 傾斜 ≤ 8°」：1万地点強（生データ）
  - 太陽光（日照3・傾斜2）→ 緯度 −85〜−86°、経度 156°/−162° 付近の尾根、日照率 ≈ 46〜49%・傾斜 3°台
  - 氷採掘（永久影まで3・傾斜2）→ 永久影クレーターの平らな床（日照 0・氷まで 0 km）
  - 有人（4条件）→ 日向の平らな尾根で永久影のすぐ隣（氷まで 10 km 前後）＝実際の月南極基地の考え方
- **注意**：日照率・傾斜の絶対値は他資料と単純比較しない。「明るい／暗い」「平ら／急」の順序を使う。
  極点から 0.7° 以内の傾斜は欠測。

## ステップ5：他の班・実在の計画と比べる（共有）

- 各班が「ミッション」「選んだ地域」「決めた緯度経度」を1〜2分で発表。
- **板書で、月全体の図に班ごとの最適地をプロット**（南極・裏側・表側にばらけることを見せる）。
- **実在の計画との比較**（cell で自動計算）：
  - Artemis III（有人・氷）＝南極（`earth_elev ≈ 0°`）。候補 Malapert Massif（急・明るい）／
    Haworth（平ら・暗い・永久影のそば）／Nobile Rim 1／de Gerlache Rim 2。NASA も1つに絞れていない。
  - LCRT（月裏側電波望遠鏡・構想）＝裏側（`earth_elev < 0`）。地球の電波が届かないことが要件。
  - Apollo 11＝赤道の海（`earth_elev ≈ +66°`・日較差 297 K）。アボート容易・通信良好だが熱と長い夜。
  - Chang'e 4／6＝裏側の海。
- **まとめの問い**：
  - 「同じデータ・同じツールなのに、なぜ班ごとに**半球**までちがった？」
  - 「『月面基地の最適地』に1つの正解はある？　氷採掘は南極で合意、でも太陽光や有人は割れる。なぜ？」
  - 「今日の分析の型（全球で俯瞰／地域を選ぶ＝目的の言語化／スコア式を設計）は、月以外のどんな問題に使える？」
  - 「このデータで『信じてよいか怪しいこと』を3つ」（日照率・傾斜の絶対値／`earth_elev_deg` は秤動無視／
    `temp_amp_K` は極で不確か／円近似の海の割合）

### 「南極が答えでよいミッションもある」――誤解しないために

Ver.3.2 の作り直しは「南極を選ばせないため」ではない。**氷採掘や Artemis 型の有人拠点にとっては、
南極が正当な結論**であり、生徒がデータからそこに至るのは正しい。狙いは
「目的によって行き先が分かれる状態を作り、南極を選ぶことが**レール**ではなく**結論**になる」こと。
氷採掘の班が南極に着き、電波天文の班が裏側に着き、両方が「自分の目的から見て正しい」と
説明できれば成功。

### 6a. 教師あり：機械が決めた基準と自分の基準を比べる

`notebooks/course_moonbase_ml.ipynb`（`moonkit_ml.py` の `train`。Colab は sklearn 標準搭載）。所要 20〜30分。

- **課題**：「日照率」と「緯度」の2つから、その場所が**有人基地に向くか**（＝ステップ4b の
  南極の有人基地スコアの上位25%か）を当てる。ラベルは日照＋`km_to_shadow`＋**傾斜**＋永久影率の4条件スコア。
  この発展ステップは南極（`極域日照`）に限定した課題。
- **ねらい**：モデルによって境界の形・正解率が違うこと。加えて、**予測したいものは描ける
  2 つの変数（日照率・緯度）だけでは決まらない**（傾斜や氷までの距離にも左右される）＝隠れた変数。
- **操作**：セルを実行 → 5モデルの決定境界・正解率・「ルールを説明できるか」が出る。
- **想定される結果**：
  - 5モデルのテスト正解率は **82〜84%**（＝真に減らせない誤差が 16% 以上ある）。「何も考えず
    『向かない』と答える」で 74.5%。傾斜が隠れた変数なので、単純モデルとの差は小さい
    （ニューラルネット・k近傍が 1〜2 ポイント上回る程度）。
  - 境界の形：ロジスティック＝まっすぐな斜め線／決定木＝階段／k近傍＝ぐにゃぐにゃ＋飛び地／
    ニューラルネット＝なめらか／ランダムフォレスト＝ブロック。
  - 境界のまわりでオレンジと青の点が入り混じる＝2 軸だけでは分けきれない。
  - `複雑さ='高い'`（k近傍 k=1 など）→ 練習正解率が上がりテスト正解率は上がらない＝**過学習**。
- **問い返しの例（まとめの議論）**：
  - 「正解率の順位と、『読めるか』の順位は同じ？　ちがう？」
  - 「正解率が 100% にならないのはなぜ？　あと何が分かれば上がる？」（傾斜・氷までの距離）
  - 「宇宙飛行士が住む場所を、正解率は少し高いが『理由を言えない』モデルで決めていい？」

### 6c. 発展：クレーターの数から絶対年代を出す（SSH 向け）

`notebooks/explore_advanced.ipynb §B`（`load('アイソクロン')` ＝ Neukum 生産関数＋編年関数の参照表）。

- 標準のステップ2は「海は新しい」まで（**相対**年代）。ここは海の一区画で D≥8km を数えて
  面積で割り、参照表と照合して **○○ Ga**（**絶対**年代）を出す。
- **想定される結果**：雨の海のあたり（緯度 22–42、経度 −35〜−8）で年代 ≈ **3.5 Ga**
  （文献：Hiesinger らの雨の海玄武岩 3.3–3.6 Ga）。区画を動かすと ±0.1 Ga、下限直径でも少し動く。
- **必ず扱う限界**：区画が小さいと統計不安定／二次クレーターの混入／参照表は特定モデル（Neukum 2001）依存。
  数値の「幅」を体感させることがねらい。工学院大の探究講座⑥と内容が重ならないか要確認（意思決定 §5-2）。

### 6b. 教師なし：クラスタリング（ラベルを作らずグループを見つける）

`notebooks/explore_clustering.ipynb`（`moonkit_ml.py` の `cluster`）。所要 20〜30分。

- **B：場所の夜の熱のふるまい**（`load('夜の温度')`）でグループ分け →「夜に暖かい＝岩が多い」場所。

## この講座で使うヘルパー関数（moonkit）

`load` / `region` / `south_pole` / `nearest` / `region_type` / `earth_elevation` / `classify_by_box` /
`near_maria` / `join_grid` / `dist_to_permanent_shadow` / `summary` / `summary_by` / `grid_count` /
`hist` / `scatter` / `diurnal_curve` / `daily_swing` / `site_score`。
いずれも中身は数行で、`notebooks/moonkit.py` を開けば読める。機械学習は含まない
（ステップ6のみ別モジュール `moonkit_ml.py`）。

`load()` のキー：`クレーター` / `クレーター深さ` / `クレーター年代` / `温度` /
`極域日照`（傾斜 `slope_deg` つき。**|緯度|≳83° の極域専用**） /
`地質`（USGS 地質図。ステップ2の答え合わせ） / `着陸地点`（実在の着陸地点・Artemis 候補地） /
**`環境`（全球1度グリッド。海陸・温度・地球の仰角。ステップ3〜4）** /
**`地域`（候補地域8件。`region_type(df, name)` で切り出す）** /
**`縦孔`（溶岩チューブの天窓。長期滞在の遮蔽拠点の候補）**。

- `region_type(load('環境'), '裏側・赤道（電波天文の候補域）')` … 名前つき地域の緯度経度の箱で切り出す
- `earth_elevation(lat, lon)` … 地球の仰角の幾何計算（正＝表側、負＝裏側）。`環境` の `earth_elev_deg` と同じ式
- `south_pole` / `dist_to_permanent_shadow` は極域専用（赤道・中緯度・裏側では使えない）

**ヘルパーの2階層**（`moonkit.py` の冒頭にも同じ分類がある）：

- **core（まず覚える）**：`load` / `region` / `nearest` / `summary` / `summary_by` / `grid_count` /
  `scatter` / `hist` / `site_score`
- **extended（必要になったら）**：`south_pole` / `north_pole` / `region_type` / `earth_elevation` /
  `near_maria` / `dist_to_permanent_shadow` / `box_area_km2` / `classify_by_box` / `join_grid` /
  `diurnal_curve` / `daily_swing`

中身が数行を超えるのは `site_score`（正規化＋重み付き和）と `region_type`（緯度経度の箱で切り出し）
だけで、どちらもコメントで手順を追える。
