# プチ探究 課題ブリーフ：月のデータで「基地の場所」を提案する

対象：プチ探究テーマ1「**人間の地球外居住で発生する問題を調査し、その解決策を提案せよ**」を
選んだグループ。要件定義書 Ver.1.5 §5（層2b）。

このブリーフは「問いの立て方」と「ゴールの形」を示すものです。**何を問うか・どの
データをどう使うか・どこを最適地とするかは、あなたたちが決めます**（探究講座の
「手順どおりに進める解析体験」とは違います）。

---

## 1. この探究のゴール

**月の公開データを根拠に、あなたたちが考える「月面基地の最適地」を提案する。**

ただし「最適」は、基地の**目的**によって変わります。まず、どんな基地をつくりたいかを
自分たちで決めてください。例（これに限らない）：

- ☀️ 太陽光発電を主力にする基地（日がよく当たる場所。極の尾根か、赤道＋大きな蓄電池か）
- 🧊 水（氷）を採る基地（氷は南極の「永久影」にありそう）
- 🔭 電波天文台（地球の電波が届かない**裏側**。温度が安定した場所）
- 🛡️ 長期滞在の拠点（放射線・微隕石・熱を**溶岩チューブ**で遮蔽したい）
- 📡 地球との通信中継基地（地球が高く見える**表側**。電力もほしい）
- 🏠 人が長く住む総合基地（電力・温度・氷・通信をバランスさせたい）

**目的によって行き先は半球ごと変わります**（氷＝南極／電波天文＝裏側／通信＝表側）。
目的が決まったら、「その目的にとって良い場所とは、データのどの値がどうなっている場所か」を
自分たちで定義します。ここが探究の中心です。`load('地域')` に候補地域タイプが8件あり、
`region_type(load('環境'), 名前)` でその範囲を切り出せます。

## 2. 使えるデータ（`moonkit` ヘルパー経由。詳しい使い方は別紙チートシート）

| 呼び出し | 中身 | 主な列 |
|---|---|---|
| `load('クレーター')` | 月全体のクレーター（Robbins DB, 直径8km以上, 36,377個） | `lat, lon, diam_km, eccentricity, ellipticity` |
| `load('クレーター深さ')` | クレーターの直径と深さ（Wang & Wu 2021, 24,982個） | `lat, lon, diameter_km, depth_km, depth_diameter_ratio` |
| `load('クレーター年代')` | クレーターの推定地質年代（DeepCraters, 18,996個） | `Lat, Lon, Diam_km, Age`(1〜5), `Age_name` |
| `load('温度')` | 月全体の温度。地点ごとに現地時間0〜23時のカーブ（Diviner, 259,200地点） | `lat, lon, temp_noon_K, temp_midnight_K, temp_diff_K, t_lt00`〜`t_lt23` |
| `load('極域日照')` | 南極・北極の日照率・永久影率・傾斜（LOLA, 157,922地点） | `lat, lon, average_illumination_percent, permanent_shadow_fraction, slope_deg` |
| `load('地質')` | 月全体の相対地質年代・海陸区分（USGS 統合地質図, 1度グリッド） | `lat, lon, relative_age, age_index`(1古〜5新)`, 区分`(海/陸) |
| `load('着陸地点')` | 実在の着陸地点・Artemis III 候補地・参照地形（29件） | `name, kind, lat, lon, terrain, year, note` |
| `load('環境')` | 月全体1度グリッドの環境指標（海陸・温度・地球の見えかた。南極以外も評価できる） | `lat, lon, 区分, age_index, temp_max_K, temp_min_K, temp_amp_K, night_min_K, noon_sun_elev_deg, earth_elev_deg`(正=表側/負=裏側) |
| `load('地域')` | 候補地域タイプ8件（赤道の海・裏側・南極・溶岩チューブ…）と緯度経度の箱 | `name, lat_min, lat_max, lon_min, lon_max, rationale, caveat` |
| `load('縦孔')` | 溶岩チューブの天窓7件（放射線・熱の遮蔽＝長期滞在の候補） | `name, lat, lon, host_terrain, opening_m, depth_m` |

`nearest(df, lat, lon)` で、グリッドのデータを「実在の地点」の緯度経度で引ける。
`region_type(df, 名前)` で、候補地域の緯度経度の箱に切り出せる。
`earth_elevation(lat, lon)` で、その地点から見た地球の仰角（正＝表側、負＝裏側）が出る。

**データの注意（提案に必ず書くこと）**
- 温度のカーブが信頼できるのは概ね **緯度 ±70度より低い**範囲。極付近はカーブが平坦・不規則になる。
- 日照率・傾斜の数字は、他の資料の数字と**そのまま比べない**。「明るい／暗い」「平ら／急」の順序は信頼できる。傾斜は極点から0.7度より外だけ。
- クレーターの「年代」は5段階の**推定**。「深さ」は数十億年で埋まった後の“今の深さ”。
- 「海」の区分：`near_maria` は円の近似（面積割合は約19%）。`load('地質')` の USGS 区分は約16%（文献値）。
- `load('環境')` は既存データ（地質図・Diviner）の結合＋幾何計算で、新規観測ではない。`earth_elev_deg` は秤動（±約7度）を無視。`noon_sun_elev_deg` は地形無視の幾何近似（極の連続日照・永久影は `極域日照` を見る）。
- `load('縦孔')` の座標は文献値の手キュレーション（全アトラスではない）。

## 3. 進め方の目安（時期は学校のプチ探究の予定に合わせる）

| 時期 | やること |
|---|---|
| **導入** | 生成AI（Gemini 等）も使いながら、このブリーフを踏まえて **自分たちの問い（RQ）** を具体化する。「月面基地の最適地はどこか」ではまだ大きすぎる。基地の目的を決め、「○○基地にとって良い場所を、△△というデータの□□という条件で探す」まで絞る |
| **追究** | データで確かめる。**まず予想を書いてから**分析する。予想と違う結果が出たら、なぜかを考える（そこが一番おもしろい）。1つの指標だけで決めず、複数の見方をする |
| （夏休み） | 追究の続き、発表の準備、わからなかったことの整理 |
| **発信** | 発表（スライドまたはポスター）。助言講師の講評をもらう |

## 4. 成果物（発信）に必ず入れる要素

1. **立てた問い（RQ）** … 最初に立てた問いと、途中で変えたなら変えた理由
2. **基地の目的と、「良い場所」の定義** … データのどの値がどうなっていれば良いとしたか
3. **使ったデータと分析** … グラフ・表。予想と結果
4. **提案する場所** … 緯度・経度。なぜそこか（他の候補と比べて）
5. **提案の限界** … データの限界、考えられていない要素、「本当はこういうデータも見たかった」

## 5. 問いの種（迷ったときのヒント。正解ではない）

- **電波天文台**：`環境` の `earth_elev_deg` が最も負（地球が深く隠れる）で、`temp_amp_K` も小さい場所は裏側のどこ？
- **太陽光発電**：「赤道の海」と「南極」で `site_score` の上位を比べる。明るさ（太陽高度）と熱の安定は両立する？
- **長期滞在の遮蔽**：`load('縦孔')` の溶岩チューブ天窓の周りの環境（温度・海陸）はどうなっている？
- **氷採掘**：`極域日照` で、永久影のふち（氷の近くで少し日も当たる）かつ平らな場所を探せる？
- 温度が一番「安定している」場所（`temp_amp_K` が小さい）はどこ？　それは日が当たる場所と一致する？
- 月の「海」と「陸」で、基地に向いているのはどっち？（着陸のしやすさ・温度・地質年代）
- クレーターの数から推定した「海は新しい」は、`load('地質')` の USGS 地質図と合っている？
- 自分たちが選んだ最適地は、`load('着陸地点')` の Artemis III 候補地や、Apollo・Chang'e とどの半球？
- 「動きにくい（どんな重みでも選ばれる）場所」はある？
