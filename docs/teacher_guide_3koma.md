### 1.2 学習者版の表計算の確認と配り方

実物：`course/student/course_moonbase_student.xlsx`（学習者版）。**リポジトリの学習者版は、Excelで再計算して保存した版**（計算結果が入っている。利用者名・作成者・保存先のパスは取り除いてある）。保護ビューでも値が見えるので、**教員が配付前に再計算する必要はない。** 教員版は `course/course_moonbase.xlsx`（計算結果は入っておらず、開くと再計算される。生徒には配らない）。
作り直すときだけ、`python course/build_course_xlsx.py --recalc`（Windows と Excel が必要。教員版と学習者版を出し、学習者版を再計算版に置き換える。所要は数十秒）。

1. **配る**：班の端末ごとにコピーを渡す（USBまたは学校の配付フォルダ）。ファイルの属性を読み取り専用にしておくと、誤って上書き保存しにくい（一般的な方法で、本資料では動作を確認していない）。班は自分のコピーを開き、**上書き保存しない**（閉じるときは「保存しない」）。入力するのは黄色いセルだけ（ステップ1の4つの緯度帯の黄色いセルは変えない）。
2. **Excelで直接上書き保存すると、自分の名前がファイルに入る。そのファイルをリポジトリに入れない。** リポジトリの版を差し替えるのは、上の `--recalc` で作り直すときだけ。
3. **検査する**（作り直したとき、または配付元を疑うとき）：`python course/check_course_xlsx.py`（学習者版・教員版の答え語とミッション語の走査、個人名・保存先パスがないこと、構造を検査。`--all` を付けると、Excel実機での再計算・入力規則・上位10の検査も行う）。配付用に別のコピーを作ったときは `--student コピーのパス`。
4. **教員機で開いて確認する**（確認後は保存せずに閉じる）：

| シート・セル | 入れる／見る | 出るはずの値 |
|---|---|---|
| ステップ1_温度 D8:D11 | 見る（黄色の緯度帯は変えない） | 295・280・236・161（K） |
| ステップ2_海と陸 B13、B27、B28 | 見る | 3.5、3.156、2.379 |

5. **値が空白に見えるとき**：計算結果が保存されているので、通常は起こらない。もし空白なら、画面上部の「保護ビュー」の「編集を有効にする」を押す（学習者版の「はじめに」シートにも書いてある）。それでも空白なら、別のソフトで開いている可能性がある。ブラウザ版Excel・Googleスプレッドシート・Chromebookは**動作を確認していない**。

### 重みの落とし穴（すべて実機で確認）

| 落とし穴 | 起きること | 声かけ・対応 |
|---|---|---|
| 地球の仰角の表側と裏側に**同じ重み** | 2つの0〜1の値は足すと必ず1になるので打ち消し合い、地球の見え方の差が順位に出ない。例：電波天文台の地域で 0・2・2・2・0 → 1位は緯度4.5・経度165.5（スコア0.355）、上位10は緯度−10.5〜13.5°・経度162.5〜178.5°と広がる（標準の重みでは緯度±4.5°・経度175.5〜178.5°） | 「このミッションに、地球は見えるほうがいい？　見えないほうがいい？」と問い、どちらか一方に置かせる |
| 重みが**全部0** | A6（4bはA13）に「【注意】重みがすべて0です。どれかを1以上にしてください」。上位10は空白 | 状態表示を読ませる |
| 地域名が空欄・不一致 | 「地域タイプを選んでください…」「【注意】C5 の地域名が『データ_地域』にありません…」。上位10は空白 | C5 のプルダウンから選ぶ（入力で防げる）。重みが 0〜5 の整数でないときは「重みは0〜5の整数で入れてください」 |
| ステップ4で**南極**を選ぶ | 「南極は『ステップ4b_スコア』を使います（ここのトップ10は参考にしない）」 | 4bへ移る |
| **単一の指標**に重み | 太陽高度だけ（赤道の海で 3・0・0・0・0）：全地点がスコア1で同点になり、上位10は緯度1.5・経度21.5〜34.5の一列（同点を行の順に並べただけ）。夜の最低温度だけ（0・0・0・0・3）：緯度1.5〜10.5°・経度21.5〜36.5° | 「1つの指標だけだと、差がつかない。ほかに何が大事？」 |
| **領域の境界に張り付く** | 電波天文台は領域が経度158〜180°で打ち切られているため、上位が180°の手前（175.5〜178.5°）に集まる（箱の人為性）。地球の仰角（裏側）だけに重みを置いても同じ範囲になる。赤道の海は太陽高度が赤道に近いほど高いため、領域の南端（緯度0°）に近い緯度1.5°に集まる | 「上位が端に集まっている。端が答えだろうか、領域の切り方のせいだろうか？」 |
| 氷採掘で**永久影率**に重み | 永久影率は「低いほどよい」で氷とは逆向き。例：永久影までの距離3・永久影率3・傾斜2（0・3・3・2）にすると、1位は緯度−88.8・経度180（日照5.5%）で、上位10は日照2.3〜30.1%・永久影まで3.4〜6.1 kmと、永久影の外側に出る | 永久影率は0にする。「その指標は、氷にとってよい向き？」 |
| **溶岩チューブ天窓**（Marius Hills）を選ぶ | `データ_環境` で10行ちょうどなので、上位10が地域全体になる。重みを変えても行の集合は変わらず、順位だけ入れ替わる（範囲の表示は緯度13.5〜16.5°・経度−58.5〜−52.5°のまま。例：2・2・0・0・1 と 0・0・0・0・3 で1位が入れ替わる）。確認の結果、スコアは0.517と0.797 | 「上位10が毎回同じ顔ぶれ。それはなぜ？」→ 地域の行数が少ないから。順位の入れ替わりを読ませる |
| 日付変更線をまたぐ領域 | 範囲の表示が「経度は日付変更線をまたぐので範囲を出しません」（裏側・南極エイトケン、南極） | 仕様。緯度の範囲だけ読ませる |

## 5. トラブル対応

| 症状 | 原因・対処 |
|---|---|
| 1. 表計算を開くと数字が空白に見える | 配付する学習者版は、計算結果が保存された版なので、通常は起こらない。もし空白なら、画面上部の「保護ビュー」の**「編集を有効にする」を押す**。それでも空白なら、別のソフトで開いている可能性がある。計算結果のない版（教員版や、`--recalc` なしで作った版）を配っていないか確かめ、`course/student/` の版を配り直す |
| 2. 表計算が開かない・壊れた | 配付元のコピーから、班の端末へ新しくコピーし直す（原本は上書きしない）。黄色いセルの入力が消えても、やり直しは1〜2分。別の端末を使う手もある |
| 3. 表計算が遅い・固まる | 教員機（本機）では、開くのに約6秒、重みを変えた後の再計算は1秒未満だった。班の端末は未測定。重い端末は、教員機の画面で数値を見せて続ける |
| 4. Webが動かない・遅い | データ層をオンにした初回の読み込みは約12.8 MB（先行の実測）。表示されない班は隣の班の画面を見る。全班で動かないときは、**§3.1 の値表を黒板（B5a）に教員が書いて続行**し、第3時の検算（0:25–0:31）は省く。自転が極端に遅いのも、端末の描画が重い目印 |
| 5. 地域名のエラー・上位10が空白 | C5 の地域名をプルダウンから選び直す。A6 の文言を読ませる（§4）。南極は4bを使う |
| 6. 座標が格子にそろわない | **異常ではない。** Webは入力値を3°格子の中心にそろえ、「入力（…）を3°格子の中心（…）にそろえてピンを立てました」と出す（例：1.5、27→1.5、28.5。0、0→1.5、1.5）。**表計算の上位点の経度（33.5、21.5など）は、Webに入れると34.5、22.5にそろう。** 月面をクリックしてピンを置いたときは、座標欄にクリックした点の値（例：52.61、88.1）がそのまま入る。「ピンを立てる」を押すと、格子の中心にそろえ直せる。ステップ1の B17・B18 は別の格子で、データにある値ちょうど（…0.25、3.25…）を入れる |
| 7. 既知の地点の近くをクリックしてもカメラが寄らない・地点名が出ない | 地点名ヒントがオフ（既定）のため。第3時の南極の検算でオンにしたときだけ、名前が出てカメラも寄る |
| 8. 地点名や「水氷候補」が出てしまう | ヒントがオンになっている。画面上部中央のスイッチをオフにする（ページを開き直してもオフに戻る） |
| 9. 座標欄でエラーのメッセージが出る | 空欄、数字でない、範囲外（緯度−90〜90、経度−180〜180。東経＋、西経−）のときで、ピンは動かない。全角の数字・マイナスも受け付ける（コードの記述） |
| 10. ピンカードの位置／右上が「データ一覧」でなく「CSV」と出る | 画面の幅が約1100px未満のときは、ピンカードが座標入力の帯の下に下がる（それより狭い小さな窓では、座標欄に重なって見える）。「データ一覧」が「CSV」と出るのも、狭いとき。ブラウザを最大化する |
| 11. ブラウザ版Excel・Googleスプレッドシート・Chromebook | **動作は未確認。** 使える端末は、授業前に開いて、数字が出ることと開く速さを確かめる |
| 12. 生徒が「データ一覧」を開いた・ファイルをダウンロードした | 授業では使わない（§0）。ダウンロードできる地域の表（`candidate_regions.csv`）には理由・弱点の列があり、答えにあたる文が入っている。開いたら閉じさせ、「配られた表計算と紙を使う」と伝える。「データ一覧」は別タブで開くので、元のタブ（Web）は残る |

### 6.3 判定のコツ

- **場所が「正しい」かは判定しない。** 行き先が分かれるのは想定で、基準ではない。見るのは、自分の目的から見た理由が数値や指標名で言えているか。
- 数値は、表計算・Webの表の値と同じならよい（§3）。丸めの違い（295と294.8など）は許容する。
- ⑧は3つの要素（重みとその理由、地域タイプと地点、弱点1つ）がそろっているか。⑨は「何を変えたか」と「上位の何がどう変わったか」の両方があるか。
- ⑪は優劣をつけない。ずれがあるか（変わらなかったか）と、その理由が書かれているか。
