- 「平らな地面なら真夜中ごろに太陽が出ない」は、|緯度|約87.8°までの場所で言える。自転軸の傾き（約1.5°）は**一般に知られた値で、同梱データでは未確認**。デモの緯度−86.75°はこの範囲内。
- **原因を断定する言い方（データ側・月側のどちらも）はしない。** 言うのは「平らな地面の考え方では説明できない」「原因は今日は調べない」まで。「実際は…だ」「データが悪い」のような言い方もしない。判断の理由は、原因がどちらでも成り立つ（緯度だけで場所を代表させる見方が合わなくなる）。
- 長さは、デモ約1分＋一言約0.8分で、2分弱。読み上げずに、2本のカーブを指しながら言う。事前に10分ほど声に出して練習しておく（準備の見積もり。仮説）。
- 生徒に「信頼できるか」「どちらが正しいか」を議論させない。そう聞かれたら「今日は、どこまで使うかを数字で決める日」と返す。

**運用の注意（実物で確認したこと）**

1. **個人の線と班の線が違うとき**：B1⑥(a)の数字2つ（B9・B10）は、画面に出ている**班が B7 に入れた線**の数字である（個人の線の数字は、その線を B7 に入れ直さないと出ない）。運用：④で個人が線を先に書く（個人で先に決める目的はここにある）→⑤で班の線を決めたら、**(a)の線を班の線に書き直し、数字2つを写す**。自分のはじめの線は、欄外に「はじめ□°」と小さく残してよい（任意。なぜ違ったかが話題になる）。班の線が決まらないときは、2つの線を順に B7 に入れて数字を見比べ、**数字で選ぶ**よう促す（多数決だけにしない）。紙の線と数字が同じ線のものであることを、机間巡視で見る。理由欄の数字も、班の線のものにそろえる。
2. **B9とグラフの最大が合わないことがある**（B9は帯の幅の設定によらず、1°ごとの行の値から求める。表計算のA8に、この関係の注がある：「帯の幅を 30 にするとグラフは30°ぶんの平均になって棒が小さく見え、幅を 1 にすると、グラフの棒が B9 と同じ1°ごとの値になる」。**グラフの位置**：B6・B7 を変えながら見る「最高が21〜3時に来る割合」のグラフが上（G5、入力欄の右）、日較差のグラフが下（G15））。例：帯の幅30°のグラフの最大は0.6％（60〜90°の帯の平均）だが、線87°以上の B9 は6.8％。帯の幅5°でも、85〜90°の帯は3.4％で、線86°の B9 は1.0％、線87°では6.8％。**生徒が戸惑ったときの返し**：「グラフは帯の平均、B9は1°ごとの行の値から出している。帯を広く取ると、特別な行が平均に薄まって見えにくい。幅を1°にすると、グラフにも6.8％（86〜87°）が出る。それが『刻むと見える』ということ。5°の帯（85〜90°）には、線の外側の行も入っている」。

### 3.3 Webと表計算の違い

## 5. トラブル対応

| 症状 | 原因・対処 |
|---|---|
| 1. 表計算を開くと数字が空白に見える | 配付する学習者版は、計算結果が保存された版なので、通常は起こらない。もし空白なら、画面上部の「保護ビュー」の**「編集を有効にする」を押す**。それでも空白なら、別のソフトで開いている可能性がある。計算結果のない版（教員版や、`--recalc` なしで作った版）を配っていないか確かめ、`course/student/` の版を配り直す |
| 2. 表計算が開かない・壊れた | 配付元のコピーから、班の端末へ新しくコピーし直す（原本は上書きしない）。黄色いセルの入力が消えても、やり直しは1〜2分。別の端末を使う手もある |
| 3. 表計算が遅い・固まる | 教員機（本機）では、開くのに約6秒、重みを変えた後の再計算は1秒未満だった。班の端末は未測定。重い端末は、教員機の画面で数値を見せて続ける |
| 4. Webが動かない・遅い | データ層をオンにした初回の読み込みは約12.8 MB（先行の実測）。表示されない班は隣の班の画面を見る。全班で動かないときは、**§3.1 の値表を黒板（B5a）に教員が書いて続行**し、第3時の検算（0:25–0:31）は省く。自転が極端に遅いのも、端末の描画が重い目印 |
| 5. 地域名のエラー・上位10が空白 | C5 の地域名をプルダウンから選び直す。A6 の文言を読ませる（§4）。南極は4bを使う |
| 6. 座標が格子にそろわない | **異常ではない。** Webは入力値を3°格子の中心にそろえ、「入力（…）を3°格子の中心（…）にそろえてピンを立てました」と出す（例：1.5、27→1.5、28.5。0、0→1.5、1.5）。**表計算の上位点の経度（33.5、21.5など）は、Webに入れると34.5、22.5にそろう。** 月面をクリックしてピンを置いたときは、座標欄にクリックした点の値（例：52.61、88.1）がそのまま入る。「ピンを立てる」を押すと、格子の中心にそろえ直せる。ステップ1の B17・B18 は別の格子で、データにある値ちょうど（…0.25、3.25…）を入れる |
| 7. 既知の地点の近くをクリックしてもカメラが寄らない・地点名が出ない | 地点名ヒントがオフ（既定）のため。第3時の南極の検算でオンにしたときだけ、名前が出てカメラも寄る |
