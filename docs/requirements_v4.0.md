### 1.3 決定事項（指導案に反映する）
1. ペアは**第1時の終了後**に確定する（地域タイプが決まってから）。§6.5(2) の「太陽光班と有人班」の例は削除。
2. 探索①（第1時 0:12〜0:18）は、W4を入れたうえで、数値を読ませるのは「最高・最低・差」だけにする。
3. 地点名・カテゴリ表示は、第1時はオフ、第3時の検算（南極）でオン。
4. 教員用の答え（教員版xlsx・当日資料）も、既存の `teacher_guide_course.md` と同じく公開リポジトリに載せる。ただし学習者向けファイルとは別名・別フォルダにし、ファイル名と冒頭に「教員用」と書く。**この扱いは利用者が後から変えられる**（push前に確認項目として報告する）。

## 2. 共通の制約
- 生徒の端末はPC（ブラウザ）。ライブAPI・外部通信なし。同梱の公開データのみ。
- 個人・学校・教員・生徒を特定できる情報を書かない。学校名・訪問日・実在の人名は教材に入れない。
- 日本語フォント：`notebooks/assets/NotoSansJP-Regular.ttf`（絵文字は描画できない）。
- 授業で使う語は指導案 §7 の語に合わせる（層名、「日較差」「地域タイプ」等）。**答えを教材に書かない**：半球・地域名とミッションの対応（氷＝南極、電波＝裏側）、標準の重み、「第一候補」「理想」。氷採掘のミッションカードに載せてよいヒントは「氷は、ずっと冷たい場所にしか残らない」だけ。
- **git の commit / push はしない**（本担当が最後にまとめて行う）。担当外のファイルを変更しない。
- 日本語を print するときは `PYTHONIOENCODING=utf-8`。一時ファイルはスクラッチパッドに置く。

### 3.2 表計算の変えないもの（紙教材とWebが依存する）
- シート名：`ステップ1_温度`、`ステップ2_海と陸`、`ステップ4_地域を選ぶ`、`ステップ4b_スコア`、`データ_地域`、`データ_環境`、`データ_南極` ほか既存のシート名を**変えない**（学習者版で非表示にしても名前は同じ）。
- 入力セル（黄色）の位置：ステップ4のC5（地域名）・C8〜C12（重み5行）、4bのC8〜C11（重み4行）。**位置を動かさない**。追加する状態表示セルや範囲表示は、既存の入力セルと重ならない場所に置く。
- 指標の順と向き（ステップ4：太陽高度・日較差・地球仰角（表側）・地球仰角（裏側）・夜の最低温度〔高いほどよい〕。4b：日照・永久影までの距離・永久影率・傾斜）。
- 地域名の文字列は `データ_地域` のA列と一致（カードもこれと同じ文字列を使う）。

### 3.3 紙教材が参照する数値
紙教材（ワークシート・黒板表・カード）は**空欄を主とする**。想定値は教員用資料にのみ書く。ジグソー5地点の座標は指導案 §7.1 のもの（Webの3°格子中心）を使い、班用ワークシートの担当地点欄は「班番号→地点」を教員が書き込む形にする（印字は5地点の候補一覧）。

### 3.4 Webの変えないもの
既定の起動状態（月の実写のみ・データ層オフ）、ピンは同時に1つ、追従・展開図・温度の℃表示。座標入力は既存の `placePinAt` 相当の処理を共用し、ホバー・クリックの動作を壊さない。

## 4. 受け入れ基準（各担当の完了条件。検証方法つき）

### X（表計算）
1. 教員版・学習者版が同じコマンド（`python course/build_course_xlsx.py`）で出る。
2. `check_course_xlsx.py` が学習者版の**全セル文字列**を検索し、答え語の検査リスト（「第一候補」「電波天文に理想」「氷採掘は南極」「見えたら失格」「裏側に」「永久影のそば」ほか、実物から拾った答えの文。企画書G1の A33・B8〜B12 を含む）が0件、かつ非表示シートを含めて確認する。リストに載せた語が教員版には存在すること（検査が空振りしていないこと）も確認する。
3. 同点解消：赤道の海で重み（3,0,0,0,0）、各地域×各単一指標、4bで（0,3,0,0）（0,0,3,0）を入れたとき、上位10の10行が**すべて異なる地点**になる（全地域×単一指標を網羅するスクリプト）。標準の重みでの1位は変更前と同じ地点。
4. C5がプルダウン（`データ_地域` の名前。南極を選んだときは「南極は4b_スコアを使う」と表示）、重みは0〜5の整数のみ受付、全部0・地域名の不一致は状態表示で分かる。**Excelで実際に開いて確認**する（PowerShellからCOM。表示・再計算・検証の動作）。
5. A4：標準の重みで、電波天文＝緯度±4.5°以内・経度175.5〜178.5°、氷採掘（4b）＝日照0%・永久影までの距離0 km が範囲表示と一致。
6. Excelで再計算した値が、`pandas` による式の再現と一致（ステップ1の4バンド295/280/236/161 K、密度比3.52、USGS年代の海3.16・陸2.38、上位10）。
7. 保存した計算結果を持つ版を出すかどうかの判断と、その理由（Excel保存後に検証・チャート・書式が壊れないか）を報告。出さない場合は、教員が開いて保存する手順を報告。

### P（紙）
1. 指導案 §5 の記録欄（日較差・密度倍率・海陸1文・理由＋重み変更1行・質疑メモ・振り返り）と、§9 の欄案が**すべて**ワークシートにある（突き合わせ表を報告に付ける）。個人用は3コマで1枚（氏名・班・各コマ欄。態度評価のため第1時の予想欄と第3時の振り返りが同じ紙）、各自由記述に2行以上。
2. 指導案の記録欄に、教員の判定用チェック欄（知・思・態）。
3. ミッションカード4枚・地域カード8枚の本文に、半球・地域名（南極・裏側・表側）とミッションの対応語、「第一候補」「理想」がない（検査スクリプトで文字列照合）。地域カードの名前・範囲は `データ_地域` と一致（スクリプトで照合）。
4. 黒板用の表はA3で、2m離れて見出しが読める文字の大きさ。月全球図は経度・緯度の目盛が10°単位で読め、**地域の範囲を載せない**（B4の番号つき全球図は別。範囲は番号のみ、色分けしない）。
5. ペア確定シートに、規則3行（同じ地域タイプ同士は組まない／奇数なら3班の輪／変更は第3時の冒頭で確定）と、10班の記入例。
6. すべてPDFで出力し、ページ数・用紙サイズ（B5／A3／A4／A5）を報告。各ページを画像にして、欄の収まり・文字の切れを確認する。

### W（Web）
1. `npm run lint`（`tsc --noEmit`）と `npm run build` が通る。
2. ブラウザで実操作して確認（ローカル配信）：W1 §7.1の5地点で全指標の表が指導案の値（約297 K→℃表示等）と一致、傾斜欠測は「―」。W2 (−88.5, 58.5)・(1.5, 169.5) を入力してピン・展開図・カードの緯度経度が一致、極・日付変更線付近でも立つ。W3 地点名ヒントの切替で南極付近のピンのカテゴリ表記が出る／出ない（既定は出ない）、リンクが別タブ、副題が授業向け。W4 赤道の海で最高・最低・差が出て、差が層の値とほぼ一致。
3. 既存の機能（ホバー、クリックでピン、追従、展開図、層切替、月画像オンオフ、自転）に退行がない（実操作）。
4. 変更点と、指導案 §7.0 に書き直すべき箇所を報告。
