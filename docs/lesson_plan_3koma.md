## 3. 単元設定の理由

### 3.1 教材観

月の公開データ（クレーターの位置・大きさ、Divinerの温度、LOLAの標高・傾斜、USGSの地質図など）を、前処理済みの表として表計算とブラウザだけで扱える教材である。
題材は「月面基地を建てるなら、どこがよいか」。基地には電力・建設・温度・通信・水といった**要素**が要り、どの要素を重んじるかで最適地が変わる。要素ごとに良い場所を言葉にし（第1・2時）、何を1番にするかを決めて重みで基地全体の位置を決める（第3時）。同じデータでも、何を重んじるかで答えが変わることを、データを根拠に判断する体験になる。
最適な設置場所を決める課題は、理数編が事例に挙げる「公的な設備等の最適な設置場所の決定方法」（本文p.25）と同じ型だが、
本案ではその**決定方法の設計は教員が与え、生徒は1番の選択・重みの設定・判断を担う**。

教材は二層に分けてある。

- **3D入口Webアプリ**：統計量の計算やスコア設計はせず、「月面を見る・触る・場所の感覚をつかむ」ことに専念する。第1時の探索と第3時の検算に使う。
- **表計算（`course_moonbase.xlsx`）**：分析の型（平均・群比較・重みづけ）を身に付ける。第2・3時の主経路。

関連する分析の型は、情報Ⅰの「データの活用」。

### 3.3 指導観

1. **足場強めのガイド型**にする。ゴールと手順を用意し、各ステップを「予想する→データで確かめる→意味づける」で短く回す。理数編が重視する「試行錯誤し、振り返るための時間や場面を十分に確保する」こと（本文p.23）とは緊張関係があり、
   **本案は振り返りの時間が短い**（各時のまとめ・第3時の振り返り6分のみ）。足場強めの型の限界として認め、プチ探究等で補う前提にする。
2. **要素ごとの分析（質的）から、重みで基地全体の位置を決める（量的）へ**進める。基地に要る要素のうち、電力は全班が扱う共通の要素（電力の行には必ず1点を置く）。建設は、全班が検算で値を読む共通の要素で、1番にはしないが、担当（分析の役）にもなる。温度・通信・水・建設は班が担当して、第1・2時に「良い場所」を分析する。**担当は分析の役で、第3時の1番は班が決める（担当と違ってよい）**。何を1番にするか、置かなかった要素を「諦めた」と言葉にすることが、目的を言葉にすること自体になる。第1時の最後に「基地の予想」（緯度経度と理由1行）を書き、第3時の振り返りで、その理由がデータで支持されたか覆ったかを見る。
   表計算では、使う範囲の入力（C5の選択・C4の線）を忘れると上位10が空白になる（§7.3）。
3. **共有で、必ず他班から質問を受ける**。班ごとの発表を並べず、班どうしのペアで同時進行にし、全班が質問を1問受けて答える。ペアは「設定→1位の分類」（§8.2）が違う班どうしで組む。第1時の共有も要素ごとに1班とし、聞いた班は質問を1つ出す。
4. **何を1番にしたかによって結論が分かれる**ことを、班の結果で見せる。月全体を採点すると、1位を分けるのは主に1番の選択（温度か通信か）で、線の位置ではない（§8.2）。
   「同じデータでも、何を重んじるかで答えが変わる」という実感につながると期待するが、**効果は未検証**。
   **線は「温度のデータを使う範囲」**で、通信や水を1番にした班には結果に関係しない。電力に1点を置く本線の重みでは、線を50〜88のどこに引いても上位10の顔ぶれまで変わらない。**このため、線を動かして1位が動かないことは、結果が線に左右されないことの確認（頑健性の確認）として使う**。
5. **第2時は「どこまで使うか」を、データの数字で判断する場面にする**。極に近い場所で温度のカーブが平らな地面の考え方では説明できない形になることを教員が見せ、**原因を問う議論はしない**（原因はこの教材では確かめていない）。生徒は「緯度の平均で場所を代表させる見方を何度まで使うか」「担当クレーターは同じ緯度の帯と違うか」を、画面の数字と理由（数字1つ）で判断して紙に記録する。線は第3時にステップ4のC4に入れる。最後の判断③で、第1時の黒板の表と今日の数字を根拠に、基地の1番を決める。判断メモは評価せず、確認印と机間巡視で見る。**効果は未検証**。

## 4. 単元の目標



1. 月の公開データ（温度・クレーター・地質年代など）から、緯度帯や群（海と陸）ごとの平均を求めて比べ、場所の特徴を数値で読み取ることができる。また、**データの数字を根拠に、緯度の平均で代表させる範囲を判断する**ことができる（**案**：この1句を目標(1)に足すかは実施前に決める）。
2. 基地に要る要素ごとに良い場所を言葉にしたうえで、何を1番にするかを決め、教員が与えた評価式の重みを入れ、1か所だけ変えて比べて重みの影響を確かめながら、根拠をもって1地点を選び、諦めた要素を含めて理由を説明することができる。
3. 第1時の「基地の予想」の理由を、データ（上位10・試行・検算の数字）に照らして、支持されたか覆ったかを確かめ、自分たちの判断を見直そうとする。

**水を1番にした班の読み替え**：目標(2)の「評価式」は、表計算の「ステップ4b_スコア」（日照率・永久影までの距離・永久影率・傾斜）とする。指標の向きは固定で、重みを置く指標と大きさを決める点は同じ。水を1番にした班は、傾斜（建設）を2番にしてよい。

**おおむね満足できる状況（思考・判断・表現。第3時）**：1番とその理由を言い、**試行2で1か所だけ変えたものを書き、1位が動いたか／動かなかったか（動かなかったときは1位の行の値で理由の見当）を書き**、上位10の様子（月全体では、いくつの場所に分かれたか、何の列で絞ったか。4bの班は日照率・永久影までの距離）に触れて1地点を選び、諦めた要素を1つ以上、検算で読んだ値（数字）つきで書く。

- **「動いた」を条件にしない**。通信を1番にした班は、電力を0にしても線を90にしても1位が動かない。**試行(c)（線を90にする）で動かなかったことを、「結果は線に左右されなかった」という確認として書けていればよい**（動かないのが正しい結果）。
- **第3時の別紙（B11。目安）は安全確認で、評価規準に入れない**。本線の設定（A〜D・線50〜88）の1位は、ほぼ全員が目安を満たす（設計時の再計算。ティコ付近の傾斜は7.91°で、目安の8°にぎりぎり。§8.2）。評価軸にすると「みんな合格」になる。
- **態度の見方**：月全体の1位は、8枚の地域カードの範囲のどれにも入らず、最も近い箱まで約19.5°以上離れる（表側の中央から赤道の海の箱まで、経度で19.5°。同梱の候補地域表との照合）。**ずれは構造的に大きくなるので、ずれの有無や大きさは見ない**（水を1番にした班の1位は、南極の箱の外側1.4〜2.6°。この場合もずれの大きさは見ない）。**予想の理由が、データで支持されたか覆ったか**の書き方で見る。判定の例（覆った例）：「表側の中央が良いと予想したが、温度を1番にしたら1位はティコ付近で、予想の場所は日較差が295.9 Kで、1位の230.4 Kより大きかった」。支持された例：「地球が高く見える場所を予想し、通信を1番にした1位の地球の仰角は88.4°だった。予想の理由はデータで支持された」。
- **第2時の判断メモ（個人用の⑥）は評価の記録に含めない**（指導のみ）。理由：思考・判断・表現の記録欄が増えすぎるのを避ける／判断の理由の文章は第3時の「選んだ理由」で評価する。**判断（線の位置、クレーターが違うか）に、正解や許容の範囲は決めない**。「画面と合う数字と、理由の1行が書いてある」かを机間巡視で見て、確認印を押す（運用は7.2.6）。記録にするかは、実施前に決める。
- 「信じきれないこと」を挙げる活動（第3時 0:44–0:50）は、**例示つきの選択式（候補から3つ選び各1文）の学習活動**で、評価の対象にしない（個数を数える課題は粘り強さの評価にならないため）。選択肢は §7.3 に置く。
- 「努力を要する」状況への手立て
  - 知識・技能：4バンド表の見方を、赤道の1行だけ教員と一緒に読む。群比較は「海の数÷海の面積割合」の式を板書で示す。判断メモが書けないとき（指導のみ）は、型「（数字）なので、（緯度）まで使う」を示す。
  - 思考・判断・表現：B2の「行と要素の対応」の表で、1番の行に3点を置いたことを確かめさせる。理由が書けないときは、型（「〜を1番にした。〜の範囲の上位10から〜に決めた（〜の値を見て）。〜は諦めた（弱点は〜）。」）を示し、検算の「失ったもの1行」を写させる。
  - 主体的に学習に取り組む態度：予想の記入欄を見せ、「最初に何と予想して、その理由はデータでどうだった？」と問う。
- 実施校の評価様式（ルーブリック）への載せ替えは、実施校と調整する。
- `docs/petit_inquiry_rubric.md`（プチ探究用の4観点）のうち R2（データや根拠の提示）と R4（限界の自覚）は流用できる。R1・R3 は、課題を与える足場強めの型には当てはまらない。

- **データ層をオンにすると、左上に凡例パネル**が出る。ここの**ドロップダウンで層を選ぶ**。層は8種：1日の温度差／夜の最低温度／正午の太陽高度／地球の仰角／全球の傾斜／地質年代／標高／1日の温度（時刻で動く層）。オンにしたときに最初に出るのは「1日の温度」。一度に重ねられる層は**1つだけ**。
- **凡例パネルの層の説明は、定義・単位・範囲だけ**で、読み取りの答え（「赤道で大きく、極で小さい」など）は書いていない。
- **月の実写画像をオフにすると**灰色の月面に層の色だけが載る。**データ層の色を読むときはオフにする**（ピンカードの表から数値を読むだけなら、オフにしなくてよい）。
- **温度は℃表示**（元データはK）。表計算（`データ_環境`）はKのままなので、**「夜の最低温度」は両者で数字が別物に見える**（例：約95 Kは約−178℃）。「1日の温度差」は差なので、値は同じで単位だけ℃になる。
- **座標入力**：画面上部中央の「緯度」「経度」の欄と「ピンを立てる」ボタン（Enterキーでもよい）。**入力は3°格子のセルの中心にそろえられ**（例：7.0°→7.5°）、ピン・展開図・ピンカードが同じ点を指し、月がその地点へ向く（ズームの距離は変えない）。
  緯度は−90〜90、経度は−180〜180（東経が＋、西経が−）。範囲外・空欄・数字以外のときはメッセージが出て、ピンは動かない。クリックでもピンを立てられる。**クリックでピンを置くと、座標欄にそのピンの緯度・経度が入る**ので、「ピンを立てる」を押すと3°格子の中心にそろえ直せる。
- **ピンは同時に1つだけ**。右上（右下のボタン列と重ならない位置。**画面の幅が約1100px未満のときは、座標入力の帯の下に下がる**）に「ピン留めした地点」のカードが出る。カードには次が出る。
  - 緯度経度。層がオンなら、その層の値。
  - **全指標の表**：1日の温度差・夜の最低温度・正午の太陽高度・地球の仰角（符号つき。正が表側、負が裏側）・全球の傾斜・地質年代・標高。**層を切り替えても表は残り**、選択中の層の行だけ色が付く。**傾斜は、データのない地点（緯度±88.5°のセル）で「―（欠測）」**（緯度85.5°では2.2°、−85.5°では9.6°と値が出る。南極付近の−88.5°では出ない）。温度は℃。表の下に、値を読んだ3°格子セルの中心が出る。
  - **「1日の温度」層をオンにすると、その地点の24時間（現地時間0〜23時）の最高・最低・差**。赤道の海ではほぼ「1日の温度差」層の値と一致する（実装の確認では最大のずれ1.7 K、緯度の絶対値30°以内）。極に近い地点ではずれ、5 Kを超えると注意書きが自動で出る（5 Kを超えてずれるセルは、**全セルの12.9%、緯度の絶対値60°以上のセルに限ると38.8%**。ずれは緯度の絶対値60°以上のセルに限られる）。
  - 「追従」ボタン：自転してもカメラが同じ経度を追い続ける（同じ地点の昼から夜への変化を観察できる）。×印でピンを消す。
- **「1日の温度」層**は、左下の「月の自転（1日の時刻）」スライダー（0〜360°）か、右下の再生ボタンで時刻が進み、昼夜の分布が動く。**このスライダーは太陽直下点の経度を決めるもので、ピンを立てた地点の現地時刻ではない。**
  再生の速さは既定で×1.0で、1周は**約1分**（コードの定数からの計算は約60秒、実測は約70秒。描画が重い端末ではさらに遅い）。×3なら約20〜25秒。
- **緯度経度**：赤道・本初子午線・北緯／南緯30°・60°の線は常時表示。データ層をオンにすると15°おきの白い格子も重なる。
- **地点名ヒント**（画面上部中央のスイッチ）：**既定はオフ**。オフの間は、ホバー・ピンカード・「選択中」の表示に既知地点の名前もカテゴリも出ず、既知の地点の近くをクリックしてもカメラは寄らない（名前を手がかりにさせないため）。
  オンにすると、近く（3°以内）の既知地点の名前が出て、地点の近くをクリックするとカメラも寄る（突然ズームして混乱する班が出うる）。**極に近いほど経度の差が小さく見えるため、南極付近では経度が離れた地点でも何かの名前が出る**（確認材料としては弱い）。**第1時はオフ、第3時の南極の検算でオンにする。**
- **左下の展開図**（正距円筒図）：水色が今見えている範囲、黄色の点がピン。
- **右上の「データ一覧」ページ**は、地域表などの説明から、候補の理由や電波天文との対応を除き、教員版xlsxへのリンクを外してある。ただしダウンロードできる `candidate_regions.csv` には、理由と弱点の列がある（生徒が自分で開けば読める）。授業では使わないと指示する。
- **右上の「データ一覧」リンクは別のタブで開く**。元のタブの月の向き・ピン・層の選択は残る。設定の保存はなく、ページを開き直すと既定に戻る（ブラウザ保存のコードがない）。
- **初回の読み込み**：コード上、データ層がオフでも、起動時に既定の「1日の温度」層用の画像24枚と値のJSONを読みに行く（`utils/diurnalLookup.ts` のコメントでは画像24枚で約8.6 MB）。さらに拡大すると、より高精細な月面画像（4K・8K）を追加で読む。台数が多いと待つ。体感の待ち時間は未計測。
- **層の値は3°×3°グリッドの最近傍セル**の値。表計算の `データ_環境` は緯度3°×経度約1.5°のため、**位置はセル単位でずれる**。
  旧版の候補（赤道の海・裏側の赤道）の上位10点で照合した範囲では、日較差は±1.2 K以内、地球の仰角は±1.1°以内、夜の最低温度は±0.9 K以内で一致した。**月全体の採点の上位10点（設定A〜D・線50〜88の23点）では、教員用資料の作成時に照合した**：Webと表計算の差は、日較差が最大11.7 K、夜の最低温度が最大7.2 K、地球の仰角が最大1.0°、太陽高度は差なし（式の再現とWebの層データの読みによる。Web画面での手元確認は未実施）。
  **南極付近の点では、日較差が最大約60 K、夜の最低温度が約10 Kずれた点がある**ので、数値の一致を検算の目的にしない。
- 表計算「ステップ4_地域を選ぶ」のスコアには傾斜は入らない（「ステップ4b_スコア」には傾斜が入る）。建設の値は、検算でWebのピンカードの傾斜を読む。
- **このアプリがしないこと**：統計量の計算、スコア設計、複数層の同時表示、複数ピン、地域タイプ（8件）や月全体の範囲表示。地域は紙の地域カードで示す。
- **公開版は、手元のコードより古い**（2026-10-06時点の公開ページは、座標欄・全指標の表がなく、副題が「公開準備中・最小版」、自転が×0.3）。公開（push）の後に再デプロイされる。**確認は公開の後に行う**。

### 7.2 第2時：緯度の平均で場所を代表させてよいのは、どこまでか（温度）／海と陸（群比較）

**目標**：緯度帯ごとの日較差（1日の温度の振れ幅）の平均を読み、**緯度の平均で場所を代表させる見方をどこまで使うかを、データの数字を根拠に判断し、クレーターで確かめる**。判断は2つ：①温度のデータを緯度何度まで使うか（線）、②担当クレーターの内部は、同じ緯度の帯の平均と違うか。その結果のうち、線は第3時にステップ4のC4に入れる（温度のデータを使う範囲。月全体を採点するときの範囲にもなる）。判断③では、第1時の黒板の表と今日の数字を根拠に、基地の1番を決める。海と陸のクレーターの密度を比べ、USGS地質図の年代と突き合わせて「海のほうが若い」を数値で確かめる。

**極に近い場所の扱い**：生徒に、原因やデータの良し悪しを議論させない。教員が24時間カーブを見せ、「平らな地面の考え方では説明できない。原因は今日は調べない」と言う（7.2.1）。生徒が決めるのは「どこまで使うか」だけで、その理由は原因がどちらでも成り立つ（緯度だけで場所を代表させる見方が合わなくなる）。

- **溶岩チューブ天窓（Marius Hills）は10行ちょうど**（地域カードの範囲をC5に選ぶと、上位10が地域全体になる）。月全体が本線なので、この地域を選ぶ班は想定しない。

**成功の基準**：どの班も、**自分が1番にした要素と、諦めた要素を、数値で説明できること**。行き先が分かれるのは想定であって基準ではない。
